# MoneyMate

Flutter-приложение для учёта личных доходов и расходов. Работает без интернета и сервера.

## Возможности

- Добавление, редактирование и удаление операций с подтверждением.
- Категория, дата и время операции; история от новых операций к старым.
- Автоматический расчёт баланса, доходов и расходов.
- История всех операций с поиском по названию, категорией и диапазоном дат (границы включены).
- Круговая диаграмма расходов по категориям за выбранный месяц.
- Отдельный бюджет для каждого месяца: лимит, потраченная сумма, остаток и превышение.
- Локальный профиль с именем и email, редактированием и выходом с подтверждением.
- Главный экран показывает пять последних операций; полная история доступна через навигацию.
- Сохранение операций, профиля и настроек между запусками.
- Русский, казахский и английский языки; светлая, тёмная и системная темы.
- Обозначения валют USD, KZT, EUR, RUB. Смена обозначения не конвертирует суммы.
- Проверка суммы, включая дробный ввод с точкой и запятой.

Данные хранятся локально через SharedPreferences. Облачной синхронизации, банковских интеграций и серверной авторизации нет. Удаление приложения может удалить его данные. Локальный профиль не является защищённым аккаунтом. Email не подтверждается. Выход завершает локальный сеанс, но сохраняет операции и бюджет на устройстве; это общий локальный набор данных, а не разделение данных нескольких аккаунтов.

## Запуск и проверки

Требуется Flutter с Dart 3.11.5 или совместимым SDK. Для iOS нужны macOS и Xcode с установленной платформой iOS.

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

Если Flutter задерживается на проверке обновлений SDK, используйте `flutter --no-version-check` перед подкомандой.

## iOS

Сборка для симулятора (подпись Apple не нужна):

```sh
flutter build ios --simulator --debug
```

Результат: `build/ios/iphonesimulator/Runner.app`. Этот файл предназначен только для симулятора, на физический iPhone он не устанавливается.

Для установки на iPhone:

1. Выполните `flutter pub get`.
2. Откройте `ios/Runner.xcworkspace` в Xcode.
3. В Runner → Signing & Capabilities выберите собственную Team и уникальный Bundle Identifier.
4. Подключите iPhone, включите Developer Mode при необходимости, выберите устройство и выполните Run.
5. Для передачи подписанной сборки используйте Product → Archive и доступный для вашей команды способ распространения.

В проекте сохранены исходные настройки подписи; на другом компьютере Team необходимо выбрать заново. Подписанный IPA или публикация в App Store требуют настройки подписи и не заменяются сборкой симулятора.

## Сценарий демонстрации

1. Создать локальный профиль.
2. Добавить доход 100000 и расход 2500: баланс 97500.
3. Изменить расход на 3000: баланс 97000.
4. Удалить расход с подтверждением: баланс 100000.
5. Переключить язык и тему.
6. Открыть историю, проверить поиск по названию, фильтр категории и период, затем сбросить фильтры.
7. Открыть статистику, выбрать месяц и проверить доли категорий.
8. Задать бюджет текущего месяца, добавить расход и проверить остаток; для другого месяца задать отдельный лимит.
9. В профиле указать имя и email, затем выйти с подтверждением: операции и бюджет сохранятся.
10. Полностью закрыть приложение и запустить снова: операции, бюджет, настройки и состояние локального сеанса восстановятся.

## Архитектура

- `setState` — состояние форм, категории, даты и времени.
- `InheritedWidget` (`AppSettings`) — локализация и форматирование валюты.
- `ScopedModel` (`UserModel`) — имя локального профиля.
- `Provider` (`TransactionsModel`, `SettingsModel`, `BudgetModel`) — операции, баланс и настройки.
- `SharedPreferences` — постоянное локальное хранение. Изменения операций сохраняются последовательно; интерфейс обновляется после успешного сохранения.

Тесты проверяют баланс, восстановление данных, последовательные записи, редактирование, удаление, повреждённые записи, настройки, совместную работу фильтров, месячную статистику, бюджет и выход из профиля.

## Кодты қай ретпен оқу керек?

1. `lib/models/transaction.dart` — бір операцияның мәліметтері: атауы, сомасы, категориясы, күні және кіріс/шығыс түрі.
2. `lib/add_transaction_screen.dart` — `TextFormField` арқылы енгізу, `if` арқылы тексеру, `setState` арқылы таңдау. `Navigator.pop` дайын операцияны қайтарады.
3. `lib/models/transactions_model.dart` — тізімге операция қосу және `for` циклімен сомаларды есептеу. Баланс = кіріс − шығыс.
4. `lib/home_screen.dart` — `Column`, `Row`, `Card`, `SingleChildScrollView` арқылы басты бет. `_openScreen` басқа экранды ашады, `_moneyCard` қайталанатын карточканы салады.
5. `lib/main.dart` — қосымшаны іске қосу және ортақ дизайн: түстер, карточкалар, өрістер, навигация.

Мысал: кіріс 10000, шығыс 2500 болса, баланс 7500. Жаңа операция сақталғанда `notifyListeners()` шақырылады, ал `context.watch` қолданылған басты бет жаңа сандарды көрсетеді.

Алдымен осы экрандар мен есептеуді түсініп алуға болады. Жобада бұрыннан бар Provider, ScopedModel, InheritedWidget және SharedPreferences ортақ деректер мен сақтауға жауап береді. Бұл жаңартуда жаңа пакет қосылған жоқ.
